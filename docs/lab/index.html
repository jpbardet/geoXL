geolabXL

geolabXL is the library of Excel functions for the soil mechanics laboratory: water content, specific gravity, grain size, soil classification, permeability and consolidation. The functions are Excel LAMBDA formulas stored inside each workbook, so they work in Excel without add-ins or macros.

What geolabXL is

geolabXL is the library of Excel functions used in the soil mechanics laboratory: water content, specific gravity, Atterberg limits, sieve and hydrometer analysis, soil classification, compaction, permeability and consolidation. Release 0.1 contains 52 functions.

The functions are ordinary Excel formulas (named LAMBDA functions) stored inside each workbook. Once a workbook has them:

  • you call them by name in any cell, for example =water_content(B9:B12, C9:C12, D9:D12);
  • nothing has to be installed in Excel: no add-in and no macros;
  • the workbook calculates offline, on your computer, like any other formula.

geolabXL is the laboratory selection of geoXL, the library used in the geotechnical engineering course: every geolabXL function is the same as in geoXL, but only the laboratory functions are installed. Check the installed release with =geolab_version(). If you are in the geotechnical engineering course, use the geoXL page instead.

What you need

  • A version of Excel that supports LAMBDA functions: Microsoft 365 (Windows or Mac) or Excel 2024. Older versions such as Excel 2019 or 2021 show #NAME?.
  • A web browser (Chrome, Edge, Safari or Firefox) and an internet connection, only while you install or update a workbook.
  • The laboratory workbooks, which are distributed through Canvas.

Install or update geolabXL in a workbook

The Install / update tab installs geolabXL in a new workbook and updates a workbook that already has an older version. It always gives you a new copy; your original file is never changed.

  1. Save the workbook and close it in Excel. Only .xlsx files are accepted; save .xls or .xlsm files as .xlsx first.
  2. Open the Install / update tab and wait until it shows the current version (geolabXL 0.1, verified).
  3. Under 1. Choose your workbook, select your file.
  4. Click Install / update geolabXL, then the download link. The copy is named after your workbook with the version added, for example consolidation (geolabXL 0.1).xlsx.
  5. Open the downloaded copy in Excel and let it calculate. Type =geolab_version() in an empty cell to check the installed release.
  6. Keep working in the new copy. Keep the original as a backup until you are satisfied.

Privacy. Everything happens in your browser. Your workbook is read and rewritten on your own computer; it is not uploaded anywhere. The internet is only used to load this page and the published library, which the page checks against its published fingerprint before using it.

What the update changes. It adds or replaces the geolabXL functions, converts older names in the formulas that use them (for example water.density → water_density, hydrometer.correction → hydrometer_correction, Step.table → Step_table), and records the installed release. Your sheets, data, formulas, charts and formatting are kept, and so are any other functions in the workbook, including geoXL functions. If something cannot be updated safely (a digitally signed workbook, or a name you defined yourself that clashes with a geolabXL name), the page tells you instead of guessing.

When to update. When your instructor announces a new release, or when a workbook shows #NAME? for a geolabXL function. Updating again with the same release changes nothing.

Using the functions

  • Function reference. The Function reference tab groups the functions by topic. Each entry gives the call, the meaning and units of every argument, what is returned, and the method. When you type a function in Excel, its description also appears.
  • Units. Masses in grams, lengths in centimetres, times in minutes and temperatures in °C, unless the reference says otherwise.
  • Columns in, columns out. Most functions accept a whole column of readings, for example all the cans of a water-content test, and return one result per row.
  • Optional arguments are shown in brackets, e.g. [details]. Leave them out, or leave an empty place between commas: =consolidation_log_time(t, d, H, , , TRUE).
  • Results that are tables. Several functions return more than one value. Enter the formula in one cell; the results “spill” into the cells below and to the right. Keep those cells empty, otherwise Excel shows #SPILL!.
  • Blank results. The water-content and specific-gravity functions return an empty cell where the masses are missing, so a partly filled data sheet stays clean.

Consolidation: three ways to find cv

Each load increment is analysed separately. Time t and dial change d are measured from the first reading of the increment; settlement may be negative (dial decreasing) or positive.

MethodHow the function works
Casagrande, log time: consolidation_log_timed0 from the parabola rule (readings at t1 and 4·t1); tangent at the steepest point; secondary line through the last readings; their intersection gives d100; cv = 0.197·Hdr²/t50.
Taylor, square-root time: consolidation_sqrt_timeThe initial straight line in d vs √t is grown automatically; the line with slope ÷ 1.15 crosses the data at √t90; cv = 0.848·Hdr²/t90.
Curve fitting: consolidation_fittingSecondary compression is located first (consolidation_creep), then Terzaghi's curve is fitted by least squares to the readings before it.

Ask for details (last argument TRUE) to get d0, d100, t50 or t90 and the construction values; the consolidation workbook uses them to draw each construction on its chart. consolidation_table applies all three methods and the secondary-compression coefficient Cαε to every load at once.

Read the results critically. The three methods rarely agree exactly; differences of 10–30 % are normal. A method returns an Excel error (#N/A, #NUM!) when its construction cannot be made on that load, for example when the curve has no distinct primary part. d100 and t100 of the log-time method are construction points, not the time of 100 % consolidation. For unloading (swelling) increments, Cαε describes the end of swelling rather than true creep.

Release notes

0.1 (November 5, 2026). First release, organized by the chapters of Experimental Soil Mechanics and taken from geoXL 0.25: water content, specific gravity, sieve and hydrometer analysis (sieve_passing, hydrometer_*), soil classification (classify_*), water density and viscosity, Mohr circle (stress_Mohr*), finite-difference seepage (seepage_*), consolidation theory (consolidation_U, consolidation_Ux) and the consolidation test methods (consolidation_log_time, consolidation_sqrt_time, consolidation_fitting, consolidation_creep, consolidation_table). Every function is the same as in geoXL. Older dotted names such as water.density are converted when a workbook is updated. One behaviour differs from the older hydrometer workbook: interpolate returns #N/A outside the data range instead of 0, so a % clay cell wrapped in IFERROR(…, "") now shows blank when the readings do not reach 0.005 mm. Native Excel release validation remains pending.

=hydrometer_correction(T)

Worksheet function

Hydrometer temperature correction (g/L) from water temperature T (°C), relative to 20 °C.

ArgumentMeaning
TWater temperature during the reading (°C); a single value or a column

Returns: Temperature correction (g/L) to add to the hydrometer reading: 1000·(0.99823 - water_density(T) - 0.000025·(T - 20)).

Method and assumptions

Zero at 20 °C. Uses water_density, so it follows the same calibration range.

=hydrometer_grainSize(T, Hr, Gs, time)

Worksheet function

Hydrometer equivalent particle diameter (mm) from Stokes law: temperature T (°C), fall depth Hr (cm), Gs and elapsed time (min).

ArgumentMeaning
TWater temperature (°C), one value or a column
HrEffective fall depth (cm), usually from hydrometer_hfall
GsSpecific gravity of the soil solids
timeElapsed time since the start of sedimentation (min)

Returns: Equivalent particle diameter (mm) from Stokes' law: SQRT(30·η·Hr/((Gs - 1)·981·ρw·time)).

Method and assumptions

Viscosity η and water density ρw come from water_viscosity(T) and water_density(T). Stokes' law assumes spherical particles settling independently.

=hydrometer_hfall(Rt, A, B, Vb, D)

Worksheet function

Hydrometer effective fall depth Hr (cm) from corrected reading Rt, calibration Hr = A·Rt + B, bulb volume Vb (cm³) and cylinder diameter D (cm).

ArgumentMeaning
RtHydrometer reading corrected for meniscus (and zero), one value or a column
ASlope of the hydrometer calibration, fall depth vs reading (cm per reading unit)
BIntercept of the hydrometer calibration (cm)
VbVolume of the hydrometer bulb (cm³)
DInside diameter of the sedimentation cylinder (cm)

Returns: Effective fall depth Hr (cm) = A·Rt + B - Vb/(2·Ac), with Ac the cylinder cross-section.

Method and assumptions

The bulb-volume term corrects for the rise of the water surface when the hydrometer is inserted.

=hydrometer_percentFiner(W, Rt, Gs, T)

Worksheet function

Hydrometer percent finer (%) from dry mass W (g), corrected reading Rt, Gs and temperature T (°C); 152H hydrometer (factor 0.6226·Gs/(Gs-1)).

ArgumentMeaning
WOven-dry mass of the soil in suspension (g)
RtHydrometer reading corrected for meniscus and zero (152H hydrometer, g/L)
GsSpecific gravity of the soil solids
TWater temperature (°C), one value or a column

Returns: Percent finer (%) = 100/W·(Rt + hydrometer_correction(T))·0.6226·Gs/(Gs - 1).

Method and assumptions

Valid for the ASTM 152H hydrometer, whose scale is calibrated for Gs = 2.65.

=seepage_eqline(xs, ys, H, level, [branch], [smooth], [nmax])

Worksheet function

Contour H=level traced cell by cell from the domain boundary; ~2 points per cell. seepage_eqline(xs,ys,H,level,[branch],[smooth],[nmax])

ArgumentMeaning
xsStrictly monotonic x coordinates, one per H column; row or column vector
ysStrictly monotonic y coordinates, one per H row; row or column vector
HTotal-head matrix; numeric values mark active nodes, nonnumeric cells mark inactive soil; rows follow ys and columns follow xs
levelScalar contour level
branch (optional)Optional 1-based index of an active-domain boundary crossing, default 1; selects a start crossing, not all connected components
smooth (optional)Optional smoothing switch, default 1: 0 returns cell-edge crossings only; any nonzero value adds a projected interior point except in thin cells
nmax (optional)Optional positive maximum number of cell-tracing iterations; nonpositive or omitted uses 2 times the number of mesh cells

Returns: Two XY columns for a contour traced through connected soil cells. Missing boundary crossing/branch returns #N/A. Smoothing can add one interior point per traversed non-thin cell.

Method and assumptions

Traces cell-edge crossings from an active-domain boundary. With smooth enabled, the midpoint is projected twice toward the bilinear contour and clamped to the cell. This is not a user-selected step-size integrator.

Closed interior contours without a boundary seed and ambiguous saddle cells are not handled generally. Reaching nmax truncates without a separate status flag.

ArgumentMeaning

=seepage_stencil(a, b, cValue, d)

Worksheet function

Interior node, 4-point stencil: (a+b+c+d)/4 - the four neighbours in any order. seepage_stencil(a,b,c,d)

ArgumentMeaning
aHead at one of the four directly adjacent nodes
bHead at a second directly adjacent node
cValueHead at a third directly adjacent node
dHead at the fourth directly adjacent node

Returns: Interior-node head estimate (a+b+cValue+d)/4, in the same units as the inputs.

Method and assumptions

For steady two-dimensional seepage in homogeneous isotropic soil on a uniform square grid, the discrete Laplace equation gives the arithmetic mean of four nearest-neighbor heads. Neighbor order is immaterial.

Intended for worksheet finite-difference equations and iterative calculation. A single call evaluates a local relation; it does not solve the entire grid. Unequal spacing or anisotropic conductivity requires different weights.

=seepage_stencil1(n, ta, tb)

Worksheet function

No-flow edge (mirror, half cell): (2n+ta+tb)/4 - n = neighbour into the soil, ta, tb = neighbours along the edge. seepage_stencil1(n,ta,tb)

ArgumentMeaning
nHead at the neighbor directed into the soil, normal to the no-flow edge
taHead at one neighbor along the no-flow edge
tbHead at the other neighbor along the no-flow edge

Returns: No-flow edge-node head estimate (2*n+ta+tb)/4.

Method and assumptions

Reflecting the interior neighbor across a zero-normal-flux edge gives a mirror-node half-cell stencil on a uniform square grid in homogeneous isotropic soil. The interior neighbor has double weight.

=seepage_stencil2(a, b)

Worksheet function

Outer corner between two no-flow edges (quarter cell): (a+b)/2. seepage_stencil2(a,b)

ArgumentMeaning

=seepage_stencil3(fa, fb, ha, hb)

=consolidation_creep(t, d, [H_0], [n_min], [k_sig], [details], [frac])

Worksheet function

Secondary compression from the straight tail of d vs log t, found by working back from the last reading. Returns C_alpha_epsilon = |slope|/H_0 (or the slope when H_0 is omitted); details = TRUE returns {value; slope; n; t_start; d_start}.

ArgumentMeaning
tElapsed times since the start of the increment (min), a column; t = 0 rows are ignored
dDial changes since the start of the increment (cm), same size as t
H_0 (optional)Optional specimen height for the strain (cm); omitted returns the slope instead of C_alpha_epsilon
n_min (optional)Optional number of last readings that start the secondary line, default 3
k_sig (optional)Optional stop threshold in standard errors, default 3
details (optional)Optional; TRUE returns the secondary-line values
frac (optional)Optional stop threshold as a fraction of the increment's total settlement, default 0.05

Returns: C_alpha_epsilon = |slope|/H_0 (strain per log cycle), or the slope (cm per log cycle). With details: {value; slope; n readings; t_start; d_start}.

Method and assumptions

The secondary line d = d_start + slope·log10(t/t_start) is grown back from the last reading; it stops at the first earlier reading off the line by more than k_sig standard errors or frac of the total settlement.

For unloading increments, or tails that are still curving, the slope describes the end of swelling rather than true creep.

=consolidation_fitting(t, d, H_dr, [skip], [n_min], [details])

Worksheet function

Coefficient of consolidation cv by least-squares fit of Terzaghi U(Tv) to the readings before secondary compression (start found by consolidation_creep). details = TRUE returns {cv; d0; d100; t50; t90; t_start; rms}.

ArgumentMeaning
tElapsed times since the start of the increment (min), a column including t = 0
dDial changes since the start of the increment (cm), same size as t
H_drDrainage path length (cm); use 1 to get cv/H_dr² (1/min)
skip (optional)Optional number of first readings excluded from the fit, default 1
n_min (optional)Optional minimum number of readings before t_start; with fewer, all readings are fitted, default 6
details (optional)Optional; TRUE returns the fit values

Returns: cv (H_dr² per min). With details: {cv; d0; d100; t50; t90; t_start; rms of the fit}.

Method and assumptions

Secondary compression is located first with consolidation_creep (its t_start); Terzaghi's d0 + (d100 - d0)·U(Tv) is then fitted by least squares to the readings before t_start.

If t_start is detected late, creep readings enter the fit and cv is underestimated; compare with the log-time and square-root-time results.

=consolidation_log_time(t, d, H_dr, [n_sec], [frac], [details])

Worksheet function

Coefficient of consolidation cv by Casagrande log-time method. t, d: elapsed time and dial change from the start of the increment. details = TRUE returns {cv; d0; d100; d50; t50; t100; t_inflection; m_primary; m_secondary}.

ArgumentMeaning
tElapsed times since the start of the increment (min), a column; t = 0 rows are ignored
dDial changes since the start of the increment (cm), same size as t; settlement may be negative or positive
H_drDrainage path length (cm); use 1 to get cv/H_dr² (1/min)
n_sec (optional)Optional number of readings in the secondary line, default 4
frac (optional)Optional fraction of the peak slope that marks the start of the plateau (fallback rule), default 0.25
details (optional)Optional; TRUE returns the construction values

Returns: cv (H_dr² per min). With details: {cv; d0; d100; d50; t50; t100; t_inflection; m_primary; m_secondary}.

Method and assumptions

Casagrande construction: d0 from the parabola rule d0 = 2·d(t1) - d(4·t1) with t1 the first reading; tangent at the steepest central slope before the secondary line; secondary line through the last n_sec readings.

If the tail is steeper than 0.6 × the primary slope, the plateau rule is used instead; if neither applies the function returns #N/A.

t100 is a construction point (theory U ≈ 95 %), not the time of 100 % consolidation. cv = 0.197·H_dr²/t50.

=consolidation_sqrt_time(t, d, H_dr, [skip], [n_min], [k_sig], [details])

Worksheet function

Coefficient of consolidation cv by Taylor square-root-of-time method; the initial straight line is detected automatically. details = TRUE returns {cv; d0; d100; t90; slope; n points}.

ArgumentMeaning
tElapsed times since the start of the increment (min), a column including t = 0
dDial changes since the start of the increment (cm), same size as t
H_drDrainage path length (cm); use 1 to get cv/H_dr² (1/min)
skip (optional)Optional number of first readings excluded from the initial line, default 1
n_min (optional)Optional minimum number of readings in the initial line, default 5
k_sig (optional)Optional stop threshold in standard errors for extending the initial line, default 2
details (optional)Optional; TRUE returns the construction values

Returns: cv (H_dr² per min). With details: {cv; d0; d100; t90; slope of the initial line (per √min); number of readings in the line}.

Method and assumptions

Taylor construction: the initial straight line in d vs √t is grown reading by reading until the next reading departs by more than k_sig standard errors on the flattening side; the line with slope ÷ 1.15 then crosses the data at √t90.

d0 is the intercept of the initial line (corrected zero); d100 = d0 + (d90 - d0)/0.9. cv = 0.848·H_dr²/t90.
