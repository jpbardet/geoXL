Bearing capacity

=GEOXL.BEARING_CAPACITY(coh, phi, q, gam, B, L, D, H, V, author, [A_])

Ultimate bearing pressure combining N factors with shape, depth and inclination factors. Inputs: coh, phi (deg), q surcharge, gam unit weight, B, L, D footing width/length/depth, H, V loads, author (terzaghi, prandtl, meyerhof, hansen, vesic, ec7).

ArgumentMeaning
cohCohesion c (kPa)
phiFriction angle φ (degrees)
qSurcharge at footing level, γ·D (kPa)
gamUnit weight of the soil below the footing (kN/m³)
BFooting width (m)
LFooting length (m); use a large value for a strip
DEmbedment depth of the footing (m)
HHorizontal load (kN); 0 for vertical loading
VVertical load (kN)
authorMethod: "terzaghi", "prandtl", "meyerhof", "hansen", "vesic" or "ec7"
A_ optionalOptional effective footing area (m²), default 1

Returns: Ultimate bearing pressure qu (kPa) = Σ s·d·i·N·load for the c, q and γ terms.

A_ is accepted but, as in the LAMBDA, not passed on to the inclination factors.

Method names must be spelled exactly as listed.
