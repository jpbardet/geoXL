#   argument: description     shown by Excel when you type the argument (keep under ~200 characters)
#   returns: ...              what the function gives back (help page only)
#   notes: ...                cautions, conventions, known behaviour (help page only; several notes lines allowed)
# The one-line function description stays in library/GeoEXCEL_v0.13.txt (the /** */ comment).
# Units: use one consistent system (e.g. m, kN, kPa) unless an argument says otherwise. Angles in degrees unless stated.

[version]
returns: Text with the add-in version and release date.

[bearing_capacity]
coh: Cohesion c (kPa)
phi: Friction angle φ (degrees)
q: Surcharge at footing level, γ·D (kPa)
gam: Unit weight of the soil below the footing (kN/m³)
B: Footing width (m)
L: Footing length (m); use a large value for a strip
D: Embedment depth of the footing (m)
H: Horizontal load (kN); 0 for vertical loading
V: Vertical load (kN)
author: Method: "terzaghi", "prandtl", "meyerhof", "hansen", "vesic" or "ec7"
A_: Optional effective footing area (m²), default 1
returns: Ultimate bearing pressure qu (kPa) = Σ s·d·i·N·load for the c, q and γ terms.
notes: A_ is accepted but, as in the LAMBDA, not passed on to the inclination factors.
notes: Method names must be spelled exactly as listed.

[bearing_depthFactors]
DB: Depth ratio D/B
phi: Friction angle φ (degrees)
author: Method: "terzaghi", "prandtl", "meyerhof", "hansen", "vesic" or "ec7"
returns: Column {dc; dq; dγ}.

[bearing_factors]
phi: Friction angle φ (degrees)
author_: Method: "terzaghi", "prandtl", "meyerhof", "hansen", "vesic" or "ec7"
returns: Column {Nc; Nq; Nγ}.

[bearing_inclinationFactors]
H: Horizontal load (kN)
V: Vertical load (kN)
BL: Shape ratio B/L
phi: Friction angle φ (degrees)
coh: Cohesion c (kPa)
author: Method: "terzaghi", "prandtl", "meyerhof", "hansen", "vesic" or "ec7"
A_: Optional footing area (m²), default 1
returns: Column {ic; iq; iγ}.
notes: Zero cohesion or zero loads can make some methods' expressions singular.

[bearing_Nq]
Phi: Friction angle φ (degrees)
author_: Method: "terzaghi", "prandtl", "meyerhof", "hansen", "vesic" or "ec7"
returns: Nq (dimensionless).

[bearing_shapeFactors]
BL: Shape ratio B/L (0 for a strip, 1 for a square)
phi: Friction angle φ (degrees)
author: Method: "terzaghi", "prandtl", "meyerhof", "hansen", "vesic" or "ec7"
opt_: Optional: any value selects the alternative Terzaghi sγ
returns: Column {sc; sq; sγ}.
notes: Supplying opt_ (even FALSE) selects the alternative branch; only its presence matters.

[bearing_Skempton]
DB: Depth ratio D/B (capped at 6)
BL: Shape ratio B/L
returns: Skempton Nc (dimensionless) for undrained bearing, qu = cu·Nc + q.

[classify_AASHTO]
pf10_: Percent passing No. 10 sieve (enter 40 for 40 %)
pf40_: Percent passing No. 40 sieve (%)
pf200_: Percent passing No. 200 sieve (%)
LL_: Liquid limit LL (%), optional
PL_: Plastic limit PL (%), optional
returns: AASHTO group (e.g. A-2-4) with group index, as text.
notes: Percentages are entered as numbers (40), not fractions (0.40).

[astm_table]
returns: 100 × 2 table {group symbol, group name} of ASTM D2487 group names.
notes: Replaces the ASTMtable name on the ASTMnames sheet; classify_ASTM uses it when its list argument is "".

[classify_ASTM]
list: Two-column table {symbol, group name}; enter "" to use the built-in ASTM_TABLE
pf4_: Percent passing No. 4 sieve (%)
pf200_: Percent passing No. 200 sieve (%)
Cu_: Coefficient of uniformity Cu = D60/D10, optional
Cc_: Coefficient of curvature Cc = D30²/(D10·D60), optional
LL_: Liquid limit LL (%), optional
PL_: Plastic limit PL (%), optional
organic_: Organic indicator: omit or 0 = inorganic, 1 = organic
returns: Text "symbol - group name", e.g. "CL - Lean clay with sand".
notes: Known issues kept from the LAMBDA: for 30–50 % coarse fraction the "with sand / with gravel" endings are swapped; organic CL and CH soils are not flagged (the test reads "MC"); organic MH looks for "OMH", which is not in the table (#REF!).
notes: Prefer CLASSIFY_ASTM2487, which follows the D2487 flow charts and needs no table.

[classify_Plasticity]
LL: Liquid limit LL (%)
PL: Plastic limit PL (%)
organic: Organic indicator: omit or 0 = inorganic, 1 = organic
returns: Symbol from the plasticity chart: CL, CH, ML, MH, OL, OH or "CL & ML".

[classify_USC]
pf4_: Percent passing No. 4 sieve (%)
pf200_: Percent passing No. 200 sieve (%)
Cu_: Coefficient of uniformity Cu = D60/D10, optional
Cc_: Coefficient of curvature Cc = D30²/(D10·D60), optional
LL_: Liquid limit LL (%), optional
PL_: Plastic limit PL (%), optional
organic_: Organic indicator: omit or 0 = inorganic, 1 = organic
returns: USCS group symbol (e.g. SW-SM, CL).
notes: The "SM-SC / GM-GC" branch cannot be reached because classify_Plasticity returns "CL & ML", not "CL-ML".

[consolidation_test]
Tarray: Column of elapsed times (min)
Xarray: Column of dial readings (same rows as Tarray)
ta: Start of the straight-line fitting window (same unit as Tarray)
tb: End of the fitting window
hi: Initial specimen height (same unit as the readings)
returns: 10 × 2 labelled table: Cv, initial height, initial reading, d0, d100, final reading, drainage length, initial/primary/secondary compression ratios.
notes: As in the LAMBDA, tc and xc both come from the y value of the first intersection, so Cv = 0.848/xc². Check against a hand construction.

[consolidation_Tv]
U: Average degree of consolidation (fraction, 0 ≤ U < 1)
returns: Time factor Tv.

[consolidation_U]
tv: Time factor Tv (single value or column)
case_: Initial excess pore pressure shape: "uniform" (default), "triangular_top", "triangular_bottom", "vshape", "saw", "sine", "parabolic", "circular"
returns: Average degree of consolidation U (fraction), one per tv.
notes: The number of Fourier terms adapts to the smallest tv.

[consolidation_Ux]
Xarray: Column of normalized depths z/H
tv: Time factor Tv
case_: Initial pore pressure shape (same choices as consolidation_U)
returns: Column of u/u0 at each depth.

[consolidation_U_approximate]
tv: Time factor Tv
returns: Average degree of consolidation U (fraction), closed-form approximation.

[consolidation_U_variable]
tv: Time factor Tv
tc: Time factor at the end of construction (load ramps up linearly until tc)
returns: Average degree of consolidation U (fraction).

[cosd]
X: Angle (degrees)
returns: cos(X).

[Coulomb_cohesiveforces]
t: Trial wedge (slip) angle (radians)
phi: Friction angle φ (degrees)
alpha: Wall inclination α (degrees; 90 = vertical)
beta: Backfill slope β (degrees)
delta: Wall friction angle δ (degrees)
g: Unit weight γ (kN/m³)
h: Wall height H (m)
coh_: Cohesion c (kPa), optional, default 0
returns: Column {W; R; P; Cs; Cw; z0; K}: wedge weight, soil reaction, wall thrust, cohesion forces on slip plane and wall, tension-crack depth, coefficient. Forces per unit length.
notes: t is in radians while the other angles are in degrees.

[Coulomb_forces]
t: Trial wedge (slip) angle (radians)
phi: Friction angle φ (degrees)
alpha: Wall inclination α (degrees; 90 = vertical)
beta: Backfill slope β (degrees)
delta: Wall friction angle δ (degrees)
g: Unit weight γ (kN/m³)
h: Wall height H (m)
returns: Column {W; R; P; K}, forces per unit wall length.

[coulomb_K]
phi: Friction angle φ (degrees)
alpha: Wall inclination α (degrees; 90 = vertical)
beta: Backfill slope β (degrees)
delta: Wall friction angle δ (degrees)
passive: Omit for active Ka; any value gives passive Kp
returns: Coulomb Ka or Kp.
notes: Supplying passive (even FALSE) selects Kp; only its presence matters.

[Coulomb_maximum]
a_: Lower search bound (any value on the first call)
b_: Upper search bound (any value on the first call)
phi: Friction angle φ (degrees)
alpha: Wall inclination α (degrees; 90 = vertical)
beta: Backfill slope β (degrees)
delta: Wall friction angle δ (degrees)
g: Unit weight γ (kN/m³)
h: Wall height H (m)
iter_: Leave empty (internal iteration counter)
returns: Column {critical slip angle (degrees); W; R; P; K}.

[coulomb_theta]
phi: Friction angle φ (degrees)
alpha: Wall inclination α (degrees; 90 = vertical)
beta: Backfill slope β (degrees)
delta: Wall friction angle δ (degrees)
returns: Critical slip angle (degrees).

[cutline]

Yarray: Column of y values of the curve
slope: Slope of the line
intercept: Intercept of the line
returns: Two columns {x, y} of the crossings, #N/A if none.

[elastic_circular_radius]
s: Stress ratio Δσz/q under the centre (0 ≤ s < 1)
returns: Ratio r/z of a circular load giving that stress ratio (for influence charts).

[elastic_circular_stress]
rValue: Radius of the loaded circle (m)
z: Depth below the centre (m)
nu_: Poisson's ratio, optional, default 0.3
returns: Row {label, Δσz/q, Δσr/q}. Multiply by the applied pressure.

[elastic_embankment]
b1z: Ratio b1/z (half crest width over depth)
b2z: Ratio b2/z (horizontal length of the side slope over depth, ≠ 0)

[elastic_Janbu_mu0]

LB: Length ratio L/B: 1, 2, 5, 10, 20, 50, 100 or 200

[elastic_Janbu_mu1]

DB: Curve: "circle" or L/B = 1, 2, 5, 10, 20, 50, 100
returns: Janbu μ1 (chart interpolation on a log axis).
notes: Argument names follow the LAMBDA; check the axis meaning against the original Janbu chart.

[elastic_lineload]

y: Depth (m)
returns: Row {label, σx, σy, τxy} per unit line load; multiply by the load (kN/m).

[elastic_lineload_horizontal]
x: Horizontal offset from the load (m)
y: Depth (m)
returns: Row {label, σx, σy, τxy} per unit horizontal line load.

[elastic_Newmark_factor]
m: Ratio B/z (rectangle side over depth)
n: Ratio L/z (other side over depth)
returns: Influence factor under a corner; Δσz = I·q.

[elastic_Newmark_stress]
x_: x coordinate of the point
y_: y coordinate of the point
z_: Depth of the point
pt: Rectangle corners (4 rows × 2 columns, opposite corners in rows 1 and 3)
returns: Influence factor at (x, y, z); Δσz = I·q.
notes: z = 0 is replaced by z = 1, as in the LAMBDA.

[elastic_pointload]
rValue: Horizontal distance from the load (m)
z: Depth (m)
nu_: Poisson's ratio, optional, default 0.3
returns: Row {label, σz, σr, σθ, τrz} per unit point load; multiply by P (kN).

[elastic_sector]

[elastic_sector_row]

[elastic_sector_slice]

[elastic_stripload]

[elastic_triangle]

[Interpolate]
