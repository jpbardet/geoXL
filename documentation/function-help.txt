#   [function_name]           exactly as in library/geoXL.txt
#   argument: description     shown by Excel when you type the argument (keep under ~200 characters)
#   returns: ...              what the function gives back (help page only)
#   notes: ...                cautions, conventions, known behaviour (help page only; several notes lines allowed)
# The one-line function description stays in library/geoXL.txt (the /** */ comment).
# Units: use one consistent system (e.g. m, kN, kPa) unless an argument says otherwise. Angles in degrees unless stated.

[version]
returns: Text with the add-in version and release date.

[bearing_capacity]
author: Method name: terzaghi, prandtl, meyerhof, hansen, vesic or ec7
phi: Soil friction angle in degrees
coh: Soil cohesion in stress units
q: Effective surcharge at foundation level, in stress units
gam: Soil unit weight consistent with footing dimensions and stress units
B: Original footing width
L: Optional length; omitted or 0 selects a strip footing
D: Optional embedment depth, default 0
eB: Optional eccentricity across B, default 0
eL: Optional eccentricity across L, default 0
use: Optional factor selector: "sdi" (default) applies shape and depth factors; "s" applies shape only; omit a letter to disable that factor
out: Optional output: 0 (default) returns total capacity; 1 returns a breakdown table; 2 returns the three capacity terms
returns: Vertical ultimate bearing pressure, a calculation table, or a three-row vector of cohesion, surcharge and soil-weight contributions.
notes: Version 0.22 changes the argument order: author comes first. Earlier calls beginning with cohesion must be revised. This function handles vertical loads; use bearing_capacity_inclined for inclined loads.
notes: Uses effective footing width for the soil-weight load term and effective width/length ratio for shape factors. Depth factors use original D/B. All terms use consistent units; for kN and metres the result is kPa.
notes: Supply positive effective footing dimensions. A strip footing uses unit out-of-plane length. This evaluates an ultimate capacity relation; apply the safety/design factors appropriate to your calculation separately.

returns: Column {dc; dq; dγ}.

[bearing_factors]

[bearing_Nq]
Phi: Friction angle φ (degrees)
author_: Method: "terzaghi", "prandtl", "meyerhof", "hansen", "vesic" or "ec7"
returns: Nq (dimensionless).

[bearing_shapeFactors]
BL: Effective width/length ratio; 0 represents a strip footing
phi: Friction angle in degrees
author: terzaghi, prandtl, meyerhof, hansen, vesic or ec7
opt_: Optional argument; supplying it selects Terzaghi circular sγ=0.6, regardless of its value
returns: Three-row vector {sc; sq; sγ} for the chosen bearing method.
notes: Updated method-specific shape expressions include Meyerhof low-friction behavior, Hansen/Vesic undrained sc=1+0.2*BL, and EC7 shape factors. Supplying opt_ is significant even when its value is FALSE.

[bearing_Skempton]

[classify_AASHTO]
pf10_: Percent passing No. 10 sieve (enter 40 for 40 %)
pf40_: Percent passing No. 40 sieve (%)
pf200_: Percent passing No. 200 sieve (%)

returns: AASHTO group (e.g. A-2-4) with group index, as text.
notes: Percentages are entered as numbers (40), not fractions (0.40).

[ASTMtable]
returns: Constant 100 × 2 table {group symbol, group name} of ASTM D2487 group names, in the original row order. Use it without parentheses: =ASTMtable.
notes: Stored in the library like the LAMBDAs, so workbooks no longer need the ASTMnames sheet. The updater replaces an older ASTMtable name that pointed to that sheet.

[classify_ASTM]
list: Two-column table {symbol, group name}: normally ASTMtable; "" also uses ASTMtable
pf4_: Percent passing No. 4 sieve (%)
pf200_: Percent passing No. 200 sieve (%)
Cu_: Coefficient of uniformity Cu = D60/D10, optional
Cc_: Coefficient of curvature Cc = D30²/(D10·D60), optional
LL_: Liquid limit LL (%), optional
PL_: Plastic limit PL (%), optional
organic_: Organic indicator: omit or 0 = inorganic, 1 = organic (organic fine soils are reported as OL or OH)
returns: Text "symbol - group name", e.g. "CL - Lean clay with sand"; organic soils give "OL - Organic clay", "OH - Sandy organic silt" etc.
notes: From 0.14 its group names agree with classify_ASTM2487, which follows the D2487 flow charts without a table.

[classify_Plasticity]

[classify_USC]

pf200_: Percent passing No. 200 sieve (%)
Cu_: Coefficient of uniformity Cu = D60/D10, optional

organic_: Organic indicator: omit or 0 = inorganic, 1 = organic
returns: USCS group symbol (e.g. SW-SM, CL).
notes: Coarse soils with CL-ML fines give SC-SM or GC-GM. Equal sand and gravel fractions classify as sand.

[seepage_stencil]

Cm: Optional meniscus correction (g/L), added to the reading; default 0
returns: Effective fall depth Hr (cm) = slope·(Rt + Cm) + intercept - volume_bulb/(2·Ac), with Ac the cylinder cross-section.
notes: The depth depends on the position of the hydrometer, read at the top of the meniscus; the dispersing agent correction does not apply to it. The bulb-volume term corrects for the rise of the water surface when the hydrometer is inserted.

[hydrometer_grainSize]
T: Water temperature (°C), one value or a column
Hr: Effective fall depth (cm), usually from hydrometer_hfall
Gs: Specific gravity of the soil solids
time: Elapsed time since the start of sedimentation (min)
returns: Equivalent particle diameter (mm) from Stokes' law: SQRT(30·η·Hr/((Gs - 1)·981·ρw·time)).
notes: Viscosity η and water density ρw come from water_viscosity(T) and water_density(T). Trailing empty cells are ignored; #N/A if T, Hr and time do not have the same number of readings. Stokes' law assumes spherical particles settling independently.

[hydrometer_percentFiner]
W: Oven-dry mass of the soil in suspension (g)
Rt: Hydrometer reading (g/L), one value or a column (trailing empty cells are ignored)
Gs: Specific gravity of the soil solids
T: Water temperature (°C), one value or a column
Cm: Optional meniscus correction (g/L); default 0
Cd: Optional dispersing agent correction (g/L); default 0
returns: Percent finer (%) = 100/W·(Rt + Cm - Cd + hydrometer_correction(T))·0.6226·Gs/(Gs - 1).
notes: Valid for the ASTM 152H hydrometer, whose scale is calibrated for Gs = 2.65. #N/A if Rt and T do not have the same number of readings.

[hydrometer_analysis]
time: Elapsed times (min), a column
Hydrometer_reading: Corrected hydrometer readings Rt, same size as time
temperature: Water temperatures (°C), same size as time
W: Oven-dry mass of soil in suspension (g)
Gs: Specific gravity of the soil solids
diameter_cylinder: Inside diameter of the sedimentation cylinder (cm)
volume_bulb: Volume of the hydrometer bulb (cm³)
slope: Slope of the fall-depth calibration (cm per reading unit)
intercept: Intercept of the fall-depth calibration (cm)
returns: Three columns per reading: fall depth (cm), equivalent diameter (mm) and percent finer (%).
notes: Combines hydrometer_hfall, hydrometer_grainSize and hydrometer_percentFiner in one call.

[buoyancy_grain_size]
time: Elapsed times since the start of sedimentation (min), one value or a column
temperature: Suspension temperatures (°C), same size as time
depth: Depth of the centre of the immersed sphere below the suspension surface (cm)
Gs: Specific gravity of the soil solids
volume: Volume of the sphere (cm³), for example (Ma - Mw)/water_density(T)
diameter_cylinder: Inside diameter of the sedimentation cylinder (cm)
returns: Equivalent particle diameter (mm) from Stokes' law: SQRT(30·η·Hr/((Gs - 1)·981·ρw·time)), with Hr = depth - volume/(2·Ac).
notes: The volume term corrects the fall depth for the rise of the suspension surface when the sphere is immersed. η and ρw come from water_viscosity and water_density.

[buoyancy_percent_finer]
mass_immersed: Mass of the sphere weighed in the suspension (g), one value or a column
temperature: Suspension temperatures (°C), same size as mass_immersed
Gs: Specific gravity of the soil solids
concentration: Initial concentration of the suspension, mass of soil / volume of suspension (g/cm³)
mass_in_air: Mass of the sphere in air Ma (g)
mass_in_water: Mass of the sphere immersed in water Mw (g)
mass_in_water_dispersing: Mass of the sphere immersed in water with dispersing agent Mr (g)
returns: Fraction finer by weight (0 to 1) = ρw·Gs·(Mr - mass_immersed)/((Ma·(Gs - 1) - Mw·Gs + Mr)·concentration).
notes: Returns a fraction, not a percent (multiply by 100 for %). Mr - mass_immersed is the buoyancy added by the particles still in suspension at the depth of the sphere.

[pipette_grain_size]
Time: Elapsed times since the start of sedimentation (min), one value or a column
depth_sampling: Depth at which the pipette sample is taken (cm), same size as Time
temperature: Suspension temperatures (°C), same size as Time
Gs: Specific gravity of the soil solids
returns: Equivalent particle diameter (mm) from Stokes' law: 20·SQRT(4.5·η·z/((Gs - 1)·ρw·981·60·Time)).
notes: Same Stokes formula as hydrometer_grainSize, with the sampling depth z as the fall distance. η and ρw come from water_viscosity and water_density.

[pipette_percent_finer]
mass_sample: Mass of the dish with the pipette sample (g): dried sample for the dry method, sample as taken for the wet method; one value or a column
mass_dish: Mass of the empty dish (g), same size as mass_sample
mass_dispersing: Mass of the blank (dispersing agent, or water and dispersing agent for the wet method) with its dish (g)
mass_dispersing_dish: Mass of the dish of the blank (g)
volume_pipette: Volume of the pipette (mL)
concentration: Initial concentration of the suspension, mass of soil / volume of suspension (g/mL)
Gs: Optional. Specific gravity of the soil solids; needed for the wet method only
temperature: Optional. Suspension temperature (°C); give it, with Gs, for the wet method only
returns: Fraction finer by weight (0 to 1) = (Ms - Md)/(concentration·V), with Ms and Md the net masses of the sample and of the blank.
notes: Dry method (temperature omitted): V is the pipette volume. Wet method: V = volume_pipette - Md/(Gs·ρw), which accounts for the water displaced by the soil in the sample. Returns a fraction, not a percent (multiply by 100 for %).

[combined_percent_finer]
method: Column naming the analysis of each row: "Sieve" for the sieve analysis, any other text (Hydrometer, Pipette, Buoyancy) for the sedimentation analysis
percent_finer: Column of the separate percents finer, as fractions or percents, one per row of method
mass_passing_200: Dry mass passing the No. 200 sieve, W200 (g)
mass_total: Total dry mass of the sample in the sieve analysis, Wtot (g)
returns: Combined percent finer of each row, in the same unit as percent_finer.
notes: p = (W200/Wtot)·p_h for the sedimentation rows (Chapter 1-7); the sieve rows are unchanged. Trailing empty rows are ignored, so the input ranges may be longer than the data.

[consolidation_log_time]
t: Elapsed times since the start of the increment (min), a column; t = 0 rows are ignored
d: Dial changes since the start of the increment (cm), same size as t; settlement may be negative or positive
H_dr: Drainage path length (cm); use 1 to get cv/H_dr² (1/min)
n_sec: Optional number of readings in the secondary line, default 4
frac: Optional fraction of the peak slope that marks the start of the plateau (fallback rule), default 0.25
details: Optional; TRUE returns the construction values
returns: cv (H_dr² per min). With details: {cv; d0; d100; d50; t50; t100; t_inflection; m_primary; m_secondary}.
notes: Casagrande construction: d0 from the parabola rule d0 = 2·d(t1) - d(4·t1) with t1 the first reading; tangent at the steepest central slope before the secondary line; secondary line through the last n_sec readings.
notes: If the tail is steeper than 0.6 × the primary slope, the plateau rule is used instead; if neither applies the function returns #N/A.
notes: t100 is a construction point (theory U ≈ 95 %), not the time of 100 % consolidation. cv = 0.197·H_dr²/t50.

[consolidation_sqrt_time]
t: Elapsed times since the start of the increment (min), a column including t = 0
d: Dial changes since the start of the increment (cm), same size as t
H_dr: Drainage path length (cm); use 1 to get cv/H_dr² (1/min)
skip: Optional number of first readings excluded from the initial line, default 1
n_min: Optional minimum number of readings in the initial line, default 5
k_sig: Optional stop threshold in standard errors for extending the initial line, default 2
details: Optional; TRUE returns the construction values
returns: cv (H_dr² per min). With details: {cv; d0; d100; t90; slope of the initial line (per √min); number of readings in the line}.
notes: Taylor construction: the initial straight line in d vs √t is grown reading by reading until the next reading departs by more than k_sig standard errors on the flattening side; the line with slope ÷ 1.15 then crosses the data at √t90.
notes: d0 is the intercept of the initial line (corrected zero); d100 = d0 + (d90 - d0)/0.9. cv = 0.848·H_dr²/t90.

[consolidation_fitting]
t: Elapsed times since the start of the increment (min), a column including t = 0
d: Dial changes since the start of the increment (cm), same size as t
H_dr: Drainage path length (cm); use 1 to get cv/H_dr² (1/min)
skip: Optional number of first readings excluded from the fit, default 1
n_min: Optional minimum number of readings before t_start; with fewer, all readings are fitted, default 6
details: Optional; TRUE returns the fit values
returns: cv (H_dr² per min). With details: {cv; d0; d100; t50; t90; t_start; rms of the fit}.
notes: Secondary compression is located first with consolidation_creep (its t_start); Terzaghi's d0 + (d100 - d0)·U(Tv) is then fitted by least squares to the readings before t_start.
notes: If t_start is detected late, creep readings enter the fit and cv is underestimated; compare with the log-time and square-root-time results.

[consolidation_creep]
t: Elapsed times since the start of the increment (min), a column; t = 0 rows are ignored
d: Dial changes since the start of the increment (cm), same size as t
H_0: Optional specimen height for the strain (cm); omitted returns the slope instead of C_alpha_epsilon
n_min: Optional number of last readings that start the secondary line, default 3
k_sig: Optional stop threshold in standard errors, default 3
details: Optional; TRUE returns the secondary-line values
frac: Optional stop threshold as a fraction of the increment's total settlement, default 0.05
returns: C_alpha_epsilon = |slope|/H_0 (strain per log cycle), or the slope (cm per log cycle). With details: {value; slope; n readings; t_start; d_start}.
notes: The secondary line d = d_start + slope·log10(t/t_start) is grown back from the last reading; it stops at the first earlier reading off the line by more than k_sig standard errors or frac of the total settlement.
notes: For unloading increments, or tails that are still curving, the slope describes the end of swelling rather than true creep.

[consolidation_table]
loads: Column of load numbers to report
load_no: Load-number column of the test data table
t_all: Total-time column of the test data table (min)
d_all: Dial-reading column of the test data table (cm)
D_ini: Initial dial reading of each load, same size as loads
D_fin: Final dial reading of each load, same size as loads
h_0: Initial specimen height (cm)
dial_0: Dial reading at the start of the test (cm)
n_drain: Optional number of drainage faces, default 2
returns: 19 columns per load: cv, d0, d100, r1, rp, rs for log time, then square-root time, then fitting, then C_alpha_epsilon.
notes: Each increment is zeroed at its first reading. H_dr is half (n_drain = 2) of the specimen height at mid-primary; C_alpha_epsilon uses the height at the start of the increment.
notes: A method that fails on a load shows its own Excel error (#N/A, #DIV/0!, #NUM!) in that load's cells only; loads with fewer than 8 readings are left blank.
notes: Time and dial values stored as text are converted to numbers.

[geolab_version]
returns: Text with the GeoLabXL version and release date, for example "GeoLabXL 0.1 (2026-11-05)".
notes: Separate from geoXL's version(), so a workbook can carry both libraries.
