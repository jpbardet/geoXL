What geoXL is

geoXL is the library of geotechnical engineering functions used in this course: bearing capacity, settlement, consolidation, earth pressure and walls, MSE walls, piles, in-situ tests, elastic stresses, slope stability, soil classification, and the geometry and plotting helpers they rely on. Release {{VERSION}} contains {{TOTAL}} functions.

Laboratory course? Use geolabXL (jpbardet.github.io/geolabXL), the laboratory library. It installs only the functions used in the soil mechanics laboratory, and its page explains them. Workbooks set up with geolabXL are refused here, so that a lab workbook does not receive the full library.

The functions are ordinary Excel formulas (named LAMBDA functions) stored inside each workbook. Once a workbook has them:

  • you call them by name in any cell, for example =bearing_factors(30, "vesic");
  • nothing has to be installed in Excel: no add-in and no macros;
  • the workbook calculates offline, on your computer, like any other formula;
  • Solver and Goal Seek work with them, because they recalculate instantly like built-in functions.

What you need

  • A version of Excel that supports LAMBDA functions: Microsoft 365 (Windows or Mac) or Excel 2024. Older versions such as Excel 2019 or 2021 show #NAME?.
  • A web browser (Chrome, Edge, Safari or Firefox) and an internet connection, only while you install or update a workbook.
  • Solver, for the exercises that use it: enable it once in Excel under Add-ins › Solver Add-in.
  • The course example workbooks, which are distributed through Canvas.

Install or update geoXL in a workbook

The Install / update tab installs geoXL in a new workbook and updates a workbook that already has an older version. It always gives you a new copy; your original file is never changed.

  1. Save the workbook and close it in Excel. Only .xlsx files are accepted; save .xls or .xlsm files as .xlsx first.
  2. Open the Install / update tab and wait until it shows the current version (geoXL {{VERSION}}, verified).
  3. Under 1. Choose your workbook, select your file.
  4. Click Install / update geoXL, then the download link. The copy is named after your workbook with the version added, for example Slopes (geoXL {{VERSION}}).xlsx.
  5. Open the downloaded copy in Excel and let it calculate. Type =version() in an empty cell to check the installed release.
  6. Keep working in the new copy. Keep the original as a backup until you are satisfied.

Privacy. Everything happens in your browser. Your workbook is read and rewritten on your own computer; it is not uploaded anywhere. The internet is only used to load this page and the published library, which the page checks against its published fingerprint before using it.

What the update changes. It adds or replaces the geoXL functions, converts older names in the formulas that use them (for example bearing.capacity → bearing_capacity, or GeoEXCEL.bearing_capacity → bearing_capacity), and records the installed release. Your sheets, data, formulas, charts and formatting are kept. If something cannot be updated safely (a digitally signed workbook, or a name you defined yourself that clashes with a geoXL name), the page tells you instead of guessing.

What it cannot change. Workbooks written for the old VBA add-ins (GeoKit, UtilKit) may call functions such as SlicesFS or Friction_Circle, whose arguments differ from the geoXL functions. These are not converted and show #NAME?; use the current course version of that workbook from Canvas, or ask your instructor.

When to update. When your instructor announces a new release, or when a workbook shows #NAME? for a geoXL function. Updating again with the same release changes nothing.

Using the functions

  • Function reference. The Function reference tab groups the functions by topic. Each entry gives the call, the meaning and units of every argument, what is returned, and notes. When you type a function in Excel, its description and argument hints also appear.
  • Units. Use one consistent system (for example m, kN, kPa). Angles are in degrees unless the help says otherwise.
  • Optional arguments are shown in brackets, e.g. [detail_]. Leave them out, or leave an empty place between commas: =f(a, b, , d).
  • Results that are tables. Many functions return several values at once. Enter the formula in one cell; the results “spill” into the cells below and to the right. Keep those cells empty, otherwise Excel shows #SPILL!.
  • Geometry inputs. Ground lines and water lines are entered as two columns (x, y) with x increasing from left to right; a point such as a circle centre is a row of two cells {x, y}.

Slope stability

The slope functions cover the four classical methods used in the course:

MethodFunctions
Undrained clay (φ = 0), circular slipslope_circle_cohesive, slope_circle_polyline_cohesive
Friction circle (c–φ)slope_friction_circle
Logarithmic spiralslope_logSpiral
Method of slices: Fellenius or simplified Bishop, optional water tableslope_slices, slope_slices_plot

A typical call of the method of slices, with the ground line in B11:C13, the circle centre in B7:C7, the radius in D7, c, φ, γ in F11, E11, D11 and 20 slices:

=slope_slices(B11:C13, B7:C7, D7, F11, E11, D11, 20, , , "Bishop")

Add a phreatic line and the unit weight of water as the 8th and 9th arguments to include pore pressure, and any value as the last argument to get the slice-by-slice table. slope_slices_plot returns the points that draw the same slices in a chart.

Finding the critical surface with Solver

The functions give the factor of safety of one trial surface. To find the critical (minimum) one, use Solver:

  1. Set Objective: the cell with the factor of safety; select Min.
  2. By Changing Variable Cells: the circle centre and radius (or only the centre when the radius is fixed by a constraint, e.g. a circle through the toe).
  3. Choose GRG Nonlinear and click Solve.
  4. Check that the solution makes sense: the circle must still cross the ground line twice. If Solver wanders into a circle that misses the slope, start again from a better guess.

Goal Seek is used in the same way when one input must be adjusted until a result reaches a target (for example the manual friction-circle iteration, where Fφ = Fc). A stored Solver answer does not update itself: if you change the slope or the soil properties, run Solver again.

Troubleshooting

What you seeWhat to do
#NAME? on a geoXL functionThe workbook does not have the function or still uses an old name: run it through Install / update. On Excel 2019/2021 LAMBDA is not supported.
#NAME? after updating an old workbookThe cell calls a function from the old VBA add-ins (e.g. SlicesFS), which cannot be converted automatically. Use the current course version of the workbook or ask your instructor.
#SPILL!Clear the cells where the result needs to spill.
#N/A from a slope functionThe trial surface does not cross the ground line twice: move the centre or change the radius.
#VALUE!Check the argument order and that ranges have the expected shape (two columns for polylines, one row for a centre).
Excel offers to “repair” the fileAccept; keep the original. If results look wrong, run the original through the updater again and report it.

Release notes

0.27 (November 7, 2026). Pipette grain-size analysis: new pipette_grain_size and pipette_percent_finer. No existing function changed. Also in geolabXL 0.3.

0.26 (November 7, 2026). Buoyancy (sphere) grain-size analysis: new buoyancy_grain_size and buoyancy_percent_finer. hydrometer_hfall, hydrometer_grainSize and hydrometer_analysis take descriptive argument names, in the same order and with the same results; hydrometer_analysis no longer refers to an undefined name. Also in geolabXL 0.2.

0.25 (November 6, 2026). Seepage: seepage_stencil to seepage_stencil3 take the cell itself first and an optional control w (ω for over-relaxation, 0 to reset), which removes the IF wrapper and speeds up the iteration; four-node formulas keep working. New seepage_psi (stream function from the heads, no second iteration) and seepage_flownet (equipotentials and flow lines for one chart from a single block). Added 13 soil-laboratory functions: water_content, specific_gravity, sieve_passing, five hydrometer_ functions, and the consolidation-test methods consolidation_log_time, consolidation_sqrt_time, consolidation_fitting, consolidation_creep and consolidation_table. They are also published, with a selection of geoXL functions, as the laboratory library geolabXL (jpbardet.github.io/geolabXL). No existing function changed.

0.24 (October 28, 2026). Added nine functions for mechanically stabilized earth (MSE) walls: mse_levels, mse_Kr, mse_Fstar, mse_active_zone, mse_reinforcement, mse_internal_stability, mse_external_stability, mse_plot_data and mse_get. They cover the AASHTO/FHWA simplified and coherent gravity earth-pressure methods, Rankine or bilinear active zones, strips, grids and geosynthetics, and ASD or LRFD checks. No existing function changed.

0.23 (October 28, 2026). Removed bearing_inclinationFactors, which bearing_capacity_inclined replaces: its out = 2 option returns the inclination factors {ic; iq; iγ} for the chosen author, evaluated consistently with the capacity. Workbooks that still call the old function keep their existing copy, and the updater lists it as retained; replace those calls when convenient. No other function changed.

0.22 (October 28, 2026). Added bearing_capacity_inclined, bearing_effective and bearing_terms; revised bearing_capacity and bearing_shapeFactors. Review older bearing_capacity calls: author now comes first, and inclined loads use bearing_capacity_inclined.

0.21 (October 24, 2026). Added CPT_classify, CPT_log, their two soil-category lookup tables, water_viscosity, and water_density, using underscore names throughout.

0.20 (October 24, 2026). Added four finite-difference head stencils: seepage_stencil (interior), seepage_stencil1 (no-flow edge), seepage_stencil2 (outer corner), and seepage_stencil3 (re-entrant corner). The 0.19 functions are unchanged. These local equations assume a uniform square grid and homogeneous isotropic soil. Native Excel validation remains pending.

0.19 (October 24, 2026). Corrected seepage_gradgrid third-point boundary selection for descending coordinates. Boundary mode edge=3 now supports both coordinate directions, including its downstream stream-function and segment routines. All other function bodies and argument lists are unchanged. Native Excel validation remains pending.

0.18 (October 24, 2026). Ten seepage_ definitions refreshed from SeepageForce_Examples_fixed2_1.xlsx, including the new seepage_cellok helper. Adds masked-cell and wall-slot awareness, cell-traced contours and outside-domain rejection. The contour argument ds is replaced by a smooth switch. For descending coordinates, avoid three-point boundary mode edge=3; use ascending coordinates or edge=2. These supplied formulas are preserved; native Excel validation remains pending.

0.17 (October 23, 2026). Nine seepage_ functions added for head interpolation, nodal gradients, stream functions, contour/flow-line coordinates and segment profiles/statistics. See the Seepage & flow nets reference for grid/boundary assumptions and chart-separator limitations. These are the workbook author's formulas; full native Excel release validation remains pending.

0.16 (October 22, 2026). The two lateral-pile reaction/shear/moment functions now use the tested V2 integration under their original names. Cohesive pressure jumps are exact, without epsilon ramps. The shared lateralpile_integrate helper reuses shearMoment. Temporary _v2 calls are migrated automatically. Output row counts change; use the full spill range for charts. Broms Example 2 now closes toe shear and moment to numerical precision. Native Excel release validation remains pending.

0.15 (October 19, 2026). New slope_slices (method of slices: Fellenius or simplified Bishop, uniform soil, optional water table) and slope_slices_plot. slope_friction_circle fixed: it returned #N/A in 0.14. All other functions are unchanged, so workbooks updated with 0.14 keep working; update them to get the new slope functions.

0.14 (October 18, 2026). The ASTM classification table is built into the library; classify_ASTM and classify_USC were corrected.
